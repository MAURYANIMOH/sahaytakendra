SAHAYTA KENDRA WEBSITE

Preview: Extract the ZIP and open index.html in a modern browser.

Included:
- Hindi/English language selector (selection remembered in this browser)
- About Me in Hindi and English
- Calculator, notes, to-do list, text case tool, age calculator, percentage calculator
- Photo select, preview, download and remove
- Public JAY AMBE DATA ENTRY APP section
- Name/mobile access request form and access-code entry form

Free hosting:
1. Create a GitHub repository and upload index.html, style.css, app.js.
2. Open Settings > Pages.
3. Select Deploy from a branch, branch main, folder /(root), and Save.
4. GitHub provides a free site URL.

Custom domain sahaytakendra.in normally needs separate domain registration and may have a fee.

IMPORTANT SECURITY LIMITATION:
The app request and code forms are currently front-end placeholders. They do not send requests, validate codes, or secure the APK. Real 30-day access requires a secure backend/API and changes inside the Android app. The server must issue unique codes, tie them to an approved user/device, enforce 30-day expiry, and allow the owner to revoke access. Never place admin secrets or master codes in website JavaScript. Add the actual APK download link once the APK is ready.

Privacy: notes/tasks stay in the visitor's browser. Selected photos are previewed/downloaded locally and are not uploaded. Public About Me omits date of birth, father's name and full village address.
